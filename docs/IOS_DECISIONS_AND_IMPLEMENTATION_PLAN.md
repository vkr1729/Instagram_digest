## 1. Locked Architectural Decisions (The Contract)

### 1.1 Ingestion & Single Source of Truth
* **Pure Consumer Client:** The iOS application has **zero Python dependencies** and executes no local scraping/ranking scripts.
* **Data Endpoint:** Consumes the remote manifest (`data.json`) generated by the backend pipeline and hosted on GitHub Pages / Cloudflare R2 (e.g. `https://vkr1729.github.io/Instagram_digest/data.json`).
* **Media Streams:** Fetches high-definition MP4 video files directly from Cloudflare R2 public bucket URLs specified in `data.json`.

### 1.2 Local Persistence & Data Sovereignty
* **100% Local-First:** All user interactions (watched history, bookmarks, daily view limits) reside entirely on-device using **SwiftData**. No sync-back to GitHub Pages or remote servers is required.
* **Weekly Rollover Invariant:**
  * When a new `week_id` / `run_date` is detected in `data.json`:
    * Existing bookmarks are preserved and carried forward.
    * The previous week's watched reel IDs are archived.
    * The previous week's local video cache (`Documents/MediaCache/{old_week_id}/`) is automatically purged from disk to prevent storage bloat.

### 1.3 AVPlayer Lifecycle & Hardware Decoder Invariant
* **Strict 3-Slot Pool (`Current - 1, Current, Current + 1`):**
  * **Slot 0 (`Current - 1`):** Paused on previous reel at current playback timestamp, ready for immediate scroll-back.
  * **Slot 1 (`Current`):** Actively rendering via `AVPlayerLayer` and looping via `AVPlayerLooper`.
  * **Slot 2 (`Current + 1`):** Preloaded `AVPlayerItem`, pre-buffered to frame 0, audio muted.
* **Decoder Protection:** Holding strictly 3 active `AVPlayer` instances keeps total video decode RAM under ~100MB and guarantees zero Apple VideoToolbox decoder throttling.
* **Rapid Fling Cancellation:** If a user rapidly flings past 5+ reels, pending pre-buffers outside the immediate `[-1, 0, +1]` window are instantly cancelled and detached.
* **Zero-Leak Invariant:**
  * All periodic time observers use explicit `[weak self]`.
  * Player layers are removed and player items set to `nil` upon view destruction.

### 1.4 Storage & Zero-Copy Disk Caching
* **Elimination of Service Worker Hacks:** The native app replaces the PWA's 265-line synthetic HTTP 206 Service Worker (`sw.js`) with direct filesystem I/O.
* **Local Path:** Downloaded MP4s are stored in `Documents/MediaCache/{week_id}/{reel_id}.mp4`.
* **Zero-Copy Playback:** If a file exists locally, `AVPlayer(url: localFileURL)` streams directly from NVMe flash storage at native bus speeds with zero network overhead.
* **Offline "Download All":** A dedicated sheet allows the user to download all ~300 reels via a background-capable `URLSession` queue with progress tracking, pause/resume, and cancellation.

### 1.5 Gesture & Feature Parity with `player.js` (100% P0)
The native app delivers exact behavioral parity with the 2,743-line `player.js`, including the newly committed long-press spatial zones:
1. **Single Tap:** Toggle play/pause (with tap-to-unmute guard).
2. **Upper-Right Long Press (`x > 0.65w, y <= 0.65h`):** 2.0x playback speed boost while finger is held down; reverts to normal speed on release (`audioTimePitchAlgorithm = .timeDomain`).
3. **Lower-Right Long Press (`x > 0.65w, y > 0.65h`):** Automatically triggers system Share Sheet (`UIActivityViewController`).
4. **Center-Lower Long Press (`0.35w <= x <= 0.65w, y > 0.65h`):** Toggles bookmark with medium haptic feedback (`UIImpactFeedbackGenerator(style: .medium)`) and animated bookmark icon pop.
5. **Horizontal Drag Scrub:** Gesture Seek HUD overlay (`⇄ mm:ss / mm:ss (+Xs)`).
6. **Mindful Daily Goal (50/day):** Real-time counter badge and mindful limit modal triggered when 50 reels are viewed in a day, offering "Take a Break" or "Snooze".
7. **Grid View & Filters:** 3-column thumbnail grid with category filter pills (AI & Tech, Health, Entertainment, etc.) and category completion progress rings.
8. **Owner Privilege:** The app treats the device as the Owner by default (no Owner Key password prompts).

### 1.6 Packaging & LiveContainer Compliance
* **Zero Dynamic Frameworks:** Built as a standalone binary via XcodeGen (`project.yml`).
* **Zero Banned Entitlements:** No push notifications (APNs), no widgets, no SiriKit, no App Groups. 100% compliant with LiveContainer sandboxing.
* **Audio Session:** `AVAudioSession.setCategory(.playback, mode: .moviePlayback)` paired with `UIBackgroundModes: audio` in `Info.plist` to allow background playback when enabled in LiveContainer.

### 1.7 CI/CD Delivery Pipeline
* **Build System:** GitHub Actions workflow (`.github/workflows/build-ipa.yml`) on macOS 14/15 runner.
* **Repository:** `vkreddy1729-ops/Instagram_digest` (uses second account GitHub Actions minutes).
* **Artifact Output:** Unsigned `InstagramDigest.ipa` uploaded to workflow artifacts for 1-tap download into LiveContainer.

## 3. Component Breakdown & File Map

### Configuration & Tooling
* `project.yml`: XcodeGen project configuration (iOS 17.0+, Swift 6 strict concurrency, bundle ID `com.instagramdigest.offline`).
* `Sources/InstagramDigest/Info.plist`: Audio background mode, document sharing, orientation settings.
* `.github/workflows/build-ipa.yml`: Automated GitHub Actions workflow compiling unsigned `.ipa` on macOS.

### Models (`Sources/InstagramDigest/Models/`)
* `ReelItem.swift`: Codable model representing individual reels (id, creatorHandle, category, rank, viewCount, caption, videoUrl, etc.).
* `DigestManifest.swift`: Root JSON payload parser (`runDate`, `count`, `items`).
* `DigestState.swift`: SwiftData `@Model` tracking watched IDs, daily view counts, snooze state, and bookmarks.

### Engine Layer (`Sources/InstagramDigest/Engine/`)
* `AVPlayerPool.swift`: Memory-bounded 3-player pool with rapid fling cancellation and zero-leak teardown.
* `MediaCacheManager.swift`: Swift Actor managing disk caching, iCloud backup exclusion, and weekly rollover purge.
* `DownloadAllCoordinator.swift`: Background `URLSession` queue managing bulk offline downloads with progress callbacks.
* `AudioSessionCoordinator.swift`: Centralized `AVAudioSession` management for playback, ducking, and unmuting.
* `DigestDataService.swift`: Network service for fetching and caching remote `data.json`.

### UI Layer (`Sources/InstagramDigest/Views/`)
* `Feed/FeedView.swift`: Root full-screen vertical pager running at 120Hz ProMotion.
* `Feed/ReelCardView.swift`: AVPlayerLayer wrapper with floating metadata (creator, rank, caption, category).
* `Gestures/FeedGestureOverlay.swift`: Spatial gesture recognizers matching `player.js` (long-press 2x, share, haptic bookmark, scrub HUD).
* `Modals/GridView.swift`: 300-reel thumbnail jump-grid with category filtering.
* `Modals/MindfulDailyModalView.swift`: 50/day mindful completion sheet with snooze actions.
* `Modals/DownloadAllSheet.swift`: Offline download manager with progress bar and cancel button.
* `Modals/BookmarksSheet.swift`: Saved reels manager.
* `InstagramDigestApp.swift`: App entry point with SwiftData `ModelContainer`.
